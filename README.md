Welcome to the official repository for the **XPACE Dance School** landing page. This project is a modern, high-performance web application designed to showcase the school's premium brand, urban aesthetics, and vision for the future of dance.

**Live Demo:** [https://xpace-premium-96518327-b22be.web.app](https://xpace-premium-96518327-b22be.web.app)

## 🚀 About The Project

XPACE is not just a dance school; it's a movement bridging art and technology. This landing page reflects that ambition through a sleek, dark-mode design, smooth animations, and a user-centric interface.

### Key Features
*   **Hero Section**: Immersive entrance with gradient typography and neon styling.
*   **Dynamic Gallery**: A masonry-style grid featuring high-quality images of performances and studio life (Gap-free layout).
*   **Interactive Schedules**: Clear, easy-to-read class schedules organized by day.
*   **Pricing Plans**: Transparent membership options with highlighted "Best Value" cards.
*   **Values & Manifesto**: Sections dedicated to the school's core philosophy (Diversão, Disciplina, Respeito).
*   **Responsive Design**: Fully optimized for mobile, tablet, and desktop experiences.
*   **Lead Capture**: Integrated CTA buttons and contact links.

## 🛠️ Tech Stack

This project is built using modern web technologies to ensure performance and scalability:

## 💻 Getting Started

Follow these steps to set up the project locally on your machine.

### Prerequisites
*   Node.js (v18 or higher recommended)
*   npm or yarn

### Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/jonathanfferreira/xpace-landing-page.git
    cd xpace-landing-page
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Run the development server**
    ```bash
    npm run dev
    ```
    Open `http://localhost:5173` (or the port shown in your terminal) to view it in the browser.

### Build for Production

To create an optimized production build:

```bash
npm run build
```
The output will be generated in the `dist` folder.

## 📦 Deployment

This project is configured for **Firebase Hosting**.

1.  **Login to Firebase**
    ```bash
    firebase login
    ```

2.  **Deploy**
    ```bash
    npm run build
    firebase deploy
    ```
